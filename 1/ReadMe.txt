ИНСТРУКЦИЯ ПО РАБОТЕ С МАКРОСОМ "БС"	
📋 Назначение макроса	
Макрос предназначен для сравнения сметных данных из двух файлов: "БЫЛО" (начальная редакция СР) и "СТАЛО" (новая редакция СР). Результат формируется в виде сводной таблицы с расчетом отклонений.	
	
📁 Требования к файлам	
1. Файл "БЫЛО"	
Обязательно должен содержать листы:	
	
"СМР уник" — данные по строительно-монтажным работам	
"ТМЦ уник" — данные по товарно-материальным ценностям	
Структура листов (колонки):	
	
Колонка 1 — Код (ИД.КЕР/ТМЦ)	
Колонка 2 — Наименование	
Колонка 3 — Единица измерения	
Колонка 4 — Объем СМР/ТМЦ Всего в СР	
Колонка 5 — СМР/ТМЦ за Единицу измерения	
2. Файл "СТАЛО"	
Обязательно должен содержать листы:	
	
"СМР уник" — данные по строительно-монтажным работам	
"ТМЦ уник" — данные по товарно-материальным ценностям	
Структура листов аналогична файлу "БЫЛО"	
3. Файл "БС" (с макросом)	
Файл, содержащий макрос	
В нем будет создан лист "Было-Стало" с результатами	
	
🚀 Порядок действий	
Шаг 1. Запустите макрос	
Нажмите кнопку БС	
ИЛИ	
Нажмите сочетание клавиш Alt+F8	
В появившемся окне выберите макрос "БС"	
Нажмите кнопку "Выполнить"	
Шаг 2. Укажите путь к файлу "БЫЛО"	
Шаг 3. Укажите путь к файлу "СТАЛО"	
Шаг 4. Ожидайте завершения обработки	
Макрос автоматически:	
	
Загрузит данные из файла "БЫЛО"	
Загрузит данные из файла "СТАЛО"	
Сопоставит позиции по кодам	
Добавит новые позиции, отсутствующие в "БЫЛО"	
Рассчитает суммы и разницу	
Шаг 5. Просмотрите результат	
После завершения обработки появится окно с проверочными суммами:	
text	
Обработка завершена.	
	
Проверочные суммы:	
	
БЫЛО:	
  СМР: 1 234 567,89 руб.	
  ТМЦ: 987 654,32 руб.	
  Всего: 2 222 222,21 руб.	
	
СТАЛО:	
  СМР: 1 345 678,90 руб.	
  ТМЦ: 1 098 765,43 руб.	
  Всего: 2 444 444,33 руб.	
Шаг 6. Проверьте таблицу "Было-Стало"	
На листе "Было-Стало" в файле "БС" будет создана таблица со структурой:	
Колонка	Назначение
A	ИД.КЕР/ТМЦ
B	Наименование КЕР/ТМЦ
C	ЕдИзм КЕР/ТМЦ
D	Объем СМР/ТМЦ Всего в СР (БЫЛО)
E	СМР/ТМЦ за ЕдИзм (БЫЛО)
F	СМР/ТМЦ Всего (БЫЛО)
G	Объем СМР/ТМЦ Всего в СР (СТАЛО)
H	СМР/ТМЦ за ЕдИзм (СТАЛО)
I	СМР/ТМЦ Всего (СТАЛО)
J	Разница (СТАЛО - БЫЛО)
	
📊 Расшифровка результатов	
Строки таблицы:	
1. ВСЕГО СМР+ТМЦ — итоговые суммы (строка 3)	
2. СМР — данные по строительно-монтажным работам (строка 4)	
3. [данные СМР] — список позиций СМР (строки 5 и далее)	
4. ТМЦ — данные по товарно-материальным ценностям	
5. [данные ТМЦ] — список позиций ТМЦ	
Формулы расчета:	
Колонка F = ОКРУГЛ(D*E; 2) — стоимость в базовом варианте	
Колонка I = ОКРУГЛ(G*H; 2) — стоимость в новом варианте	
Колонка J = I - F — разница (отклонение)	
Сравнение данных:	
При совпадении кода (колонка A) — данные обновляются	
При появлении нового кода — строка добавляется в таблицу	
При отсутствии кода в файле "СТАЛО" — данные в колонках G-J остаются пустыми	
	
⚠️ Важные замечания	
1. Корректность данных — макрос проверяет только файлы с правильной структурой. Убедитесь, что листы называются точно "СМР уник" и "ТМЦ уник".	
2. Коды позиций — должны быть уникальными в пределах каждого листа.	
3. Форматы файлов — поддерживаются все форматы Excel (.xlsx, .xlsm, .xls).	
4. Данные считываются со 2-й строки — первая строка считается заголовком и игнорируется.	
5. Числовой формат — все суммы отображаются в русской локализации:	
	
Разделитель тысяч: пробел	
Десятичный разделитель: запятая	
Два знака после запятой	
	
🛠 Возможные ошибки и их решение	
Ошибка	Решение
"В файле нет листа СМР уник"	Проверьте название листа в файле
"Файл не выбран"	Нажмите "Отмена" или выберите файл
"Нет данных для копирования"	В файле нет данных во 2-й и последующих строках
Переполнение памяти	Закройте другие программы, повторите попытку
	
💡 Советы	
1. Перед запуском макроса закройте все лишние файлы Excel	
2. Убедитесь, что файлы "БЫЛО" и "СТАЛО" не открыты в других программах	
3. При большом количестве данных (более 10 000 строк) макрос может работать медленнее	
4. Результат сохраняется на листе "Было-Стало" — его можно скопировать в другой файл
