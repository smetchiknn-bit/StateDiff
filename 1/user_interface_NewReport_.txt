Описание интерфейса главного окна приложения журнал КС6
Общая структура
Интерфейс построен по принципу «чертёжного стола» — фон имитирует миллиметровую бумагу с сеткой 26px, на которой расположены карточки с жёсткими смещёнными тенями (эффект бумаги на столе).
Фон (три слоя)
Слой 0: базовый цвет #eef2ec + миллиметровая сетка из линий 1px rgba(21,38,32,0.05) по обеим осям
Слой 1 (fixed, под контентом): два мягких радиальных градиента — rgba(30,113,69,0.12) справа сверху и rgba(30,113,69,0.08) слева снизу
Слой 2: контент с z-index: 1
Декоративные плавающие элементы (символы Σ, ₽, =) с анимацией покачивания float-soft (9–12 секунд) создают ощущение живого пространства.
Шапка приложения (Header)
Расположение: фиксированная вверху, высота ~80px, тёмно-зелёный фон #123f28 с белой типографикой.
Левая часть
Логотип-штамп: квадрат 40×40px, зелёный #1e7145, белый текст "КС6" шрифтом Unbounded (15px, bold), жёсткая тень 3px 3px 0 rgba(0,0,0,0.25)
Название: "Мастер нового периода" — Unbounded 17px, semibold, белый
Подзаголовок: "журнал КС‑6 · вставка трёх колонок периода с формулами и форматированием по ТЗ" — 11px, rgba(255,255,255,0.65)
Правая часть (появляется после загрузки файла)
Статус файла: моноширинный чип с иконкой файла и именем (скрыт на мобильных)
Кнопка "Сброс": ghost-стиль с hover-эффектом (красная рамка при наведении)
Строка формул (внизу шапки)
Фон rgba(0,0,0,0.2), отделена от шапки полупрозрачной границей
Слева: адрес ячейки в зелёном чипе (например, BR24:BT24)
Символ ƒx (как в Excel)
Псевдо-формула: =НОВЫЙ_ПЕРИОД("Лист1"; заголовок=24; ключ=L; вставка_после=BQ) или =ожидание_параметров(загрузите книгу…)

Расположение: сразу под шапкой, горизонтальная навигация из 4 шагов.

Шаг 1: Книга и лист журнала
До загрузки файла
Заголовок секции:
Иконка листа (SVG, 16px, зелёный)
Текст "Книга и лист журнала" — Unbounded 15px, semibold
Справа (после загрузки): чип с количеством листов
Dropzone (зона загрузки):
Размер: растягивается на всю ширину карточки, высота ~200px
Рамка: пунктирная border-2 border-dashed, цвет #cfd9d0
Фон: rgba(240,247,242,0.4) (полупрозрачный зелёный туман)
Центрированный контент:
Иконка загрузки: белый квадрат 56×56px с зелёной рамкой, внутри SVG-стрелка вверх (24px, зелёный)
Заголовок: "Перетащите журнал КС‑6 сюда" — Unbounded 15px, semibold
Подсказка: "или нажмите, чтобы выбрать файл · .xlsx / .xlsm" — 13px, серый
Важное примечание: "Файл обрабатывается локально в браузере и никуда не отправляется. Исходное оформление книги полностью сохраняется — поверх него добавляется только форматирование нового периода." — 12px, серый, max-width 400px
Состояния dropzone:
Обычное: описано выше
Hover: рамка становится зелёной #1e7145, фон #f0f7f2, иконка поднимается -translate-y-1
Drag-over (перетаскивание файла): масштаб scale-[1.01], рамка зелёная, фон #e0efe5, иконка с зелёной рамкой
Loading: иконка заменяется на спиннер (вращающаяся окружность)
После загрузки файла
Карточка статуса файла:
Фон rgba(238,242,236,0.7), рамка #cfd9d0
Слева: зелёный квадрат с иконкой файла (17px)
Текст: имя файла моноширинным шрифтом (13.5px, semibold) + количество листов
Справа: кнопка "Заменить файл" (ghost-стиль)
Предупреждение для .xlsm (если файл содержит макросы):
Фон #fdf3e2 (янтарный), рамка #a15c07
Иконка предупреждения ⚠️
Текст: "Книга содержит макросы (.xlsm). Результат будет сохранён как .xlsx — VBA‑макросы в него не переносятся (данные и оформление сохраняются)."
Список листов:
Каждый лист — отдельная карточка с радиокнопкой
Активный лист: зелёная рамка #1e7145, фон #f0f7f2, чип "целевой лист" справа
Неактивные: белая карточка, hover с подъёмом
Формат: имя листа (14px, semibold) + размер (например, "100 стр × 20 кол")
Автовыбор: лист с названием, содержащим "КС6", или первый лист
Кнопка навигации:
"Далее: разметка таблицы →" — зелёная кнопка с жёсткой тенью
Активна только после выбора листа
Правый сайдбар (всегда виден)
Карточка 1: Предпросмотр зоны вставки
Заголовок: "Зона вставки · предпросмотр" + чип с адресом (например, "BR–BT")
Мини-Excel таблица:
Буквенные шапки колонок (серые для существующих, зелёные для новых)
Ключевая колонка обведена зелёным с маркером ◆
Колонка "кол-во на начало" с янтарным маркером ◆
Новые колонки с анимацией cell-flash (вспышка зелёным)
Заливки по ТЗ: серый #D8D8D8 для шапки, зелёный #E2EFD9 для ТМЦ, золотистый #FFD965 для ГР
Легенда внизу с счётчиками КЕР/ТМЦ/ГР
Карточка 2: Определено по листу
Список параметров в две колонки:
Лист, Строка заголовков, Ключевая колонка, Кол-во на начало периода, Последняя непустая, Последняя строка, Цена СМР, Цена ТМЦ
Значения моноширинным шрифтом, жирные
Карточка 3: Регламент вставки
Фон rgba(240,247,242,0.6), рамка зелёная
Заголовок с иконкой штампа
Нумерованный список из 6 пунктов (краткое описание процесса)
Ключевые UX-паттерны
Автоопределение с возможностью переопределения: все параметры определяются автоматически при загрузке, показываются в сайдбаре, но могут быть изменены на шаге 2.
Живой предпросмотр: мини-Excel обновляется при каждом изменении любого параметра, новые колонки "вспыхивают" анимацией.
Прогресс-рейл с обратной связью: текущий шаг имеет анимацию (бегущий пунктир), выполненные шаги можно кликать для возврата.
Индикатор безопасности: фраза "🔒 файл обрабатывается локально, никуда не отправляется" всегда видна в прогресс-рейле, а также повторяется в dropzone — это ключевое сообщение о приватности.
Предметный первый экран: вместо абстрактного hero — сразу зона загрузки с понятной инструкцией и гарантией локальной обработки.
Технические детали реализации
Стек: React + TypeScript + Tailwind CSS v4
Шрифты: Unbounded (display), IBM Plex Sans (body), IBM Plex Mono (код/параметры)
Анимации: rise-in, cell-flash, dash-move, float-soft, pulse-ring
Иконки: инлайн SVG компоненты (без внешних библиотек)
Адаптивность: мобильная версия скрывает длинные подписи шагов, статус файла, индикатор безопасности
